# RosterBuddy web app

Hosted web build for the reviewed RosterBuddy sharing Sandbox flow.

- App: https://donkeyworks26.github.io/rosterbuddy-site/
- Privacy: https://donkeyworks26.github.io/rosterbuddy-site/privacy-policy.html
- Support: https://donkeyworks26.github.io/rosterbuddy-site/support.html
